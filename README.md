## Adopt the site

### Prerequisites
- [Hugo Extended](https://gohugo.io/getting-started/installing/) (v0.147.9+)

### Local development

1. Clone the repository:
```git clone https://github.com/bethanyjep/paper-blog.git ```
2. Navigate to the folder:
```cd paper-blog```
3. Start development server: 
```hugo server -D```
4. Build for production: ```hugo```

### Project Structure
```
├── content/
│   ├── posts/          # Blog posts
│   ├── archives.md     # Archives page
│   └── search.md       # Search page
├── themes/PaperMod/    # Theme files
├── public/             # Generated site
└── hugo.yaml           # Site configuration
```

## Writing

Posts are written in Markdown and stored in `content/posts/`. Each post includes frontmatter with:
- `title` - Post title
- `date` - Publication date
- `tags` - Categories for the post
- `draft` - Set to `false` to publish
