This workshop provides a hands-on introduction to GitHub Models, allowing participants to experiment with leading AI models without complex setup. It's designed as introductory content for Global AI Bootcamps worldwide (~125 locations).

## Key Features

- **Free Access**: Uses GitHub Models which provides free access to leading models from Azure AI Model Catalog
- **No Complex Setup**: Only requires a personal token to get started
- **Model Comparison**: Compare different AI models before production use

## What You'll Learn

- How to access and use GitHub Models
- Comparing different AI models for various tasks
- Transitioning from experimentation to production

Perfect for developers, data scientists, and AI enthusiasts looking to explore AI models without barriers!
