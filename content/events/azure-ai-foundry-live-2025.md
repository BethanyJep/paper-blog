## Prompty Deep Dive

### What is Prompty?

Prompty serves as a *bridge beyond simple API calls* when working with AI models, allowing you to create a *custom model playground* directly in Visual Studio Code.

### Three Main Components:

1. Specification (.prompty file)
- Prompty file format using markdown with front matter
- Structured approach to prompt engineering
- Version control friendly format

2. Tooling (VS Code Extension)
- Integrated development experience
- Syntax highlighting and IntelliSense
- Real-time prompt testing and validation

3. Runtime (Prompty to Code)
- One-click conversion to production code
- Support for multiple frameworks:
  - Python
  - C#
  - Semantic Kernel
  - LangChain

### Why Prompty Matters

Prompty transforms prompt engineering from ad-hoc API calls into a **structured, repeatable development process** with proper tooling support and code generation capabilities.
