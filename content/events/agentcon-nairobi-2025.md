Participated in the inaugural AgentCon Nairobi 2025 at Strathmore University, delivering a comprehensive session on building AI agents with Prompty and Azure AI Foundry.

## Session: Building AI Agents with Prompty and Azure AI Foundry

{{< speakerdeck 21c03e57934d4c7dbd6478ed2091096e >}}

This session showcased an AI agent was built using Prompty and Azure OpenAI to automate GitHub issue tagging, a small yet time-consuming task in open-source projects. It offered a behind-the-scenes look at prompt engineering techniques used to streamline the contributor experience, improve repository hygiene, and convert repetitive maintenance chores into intelligent automation. The talk demonstrated how AI agents can shift focus away from routine work and toward what truly matters: empowering developer communities.

This session provided practical guidance on developing AI agents, combining Prompty for structured prompt engineering with Azure AI Foundry's comprehensive agent development platform.
