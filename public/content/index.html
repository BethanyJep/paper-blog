Workshops and labs#

Hands-on sessions I have written or delivered, most of them built to be run at your own pace.

Biashara Agent Workshop — Safaricom Decode#

Build a bilingual English and Swahili AI agent for a Nairobi restaurant using the Microsoft Foundry Toolkit in VS Code. Covers agent setup, system prompts, MCP tools for grounded answers, evaluation, a Flask chat interface, and exporting to production code with Microsoft Agent Framework.

LAB521: Improving Agent Behavior Using Reinforcement Learning from Traces#

Delivered at Microsoft Build 2026. Agents often work, but prompts alone make their behaviour hard to control. This lab starts with a working agent, inspects its execution traces, defines “good behaviour” using evaluation graders, and applies reinforcement fine-tuning to reinforce better decisions — without redesigning the agent.

BRK443: Efficient Model Customization with Microsoft Foundry#

Microsoft AI Tour 2025/26. When does fine-tuning actually make sense? This session walks through the customization options in Microsoft Foundry, then gets hands-on with synthetic data generation, distillation for cutting cost, and SFT for shaping tone.

BRK441: Build and Launch AI Agents Fast with Foundry Toolkit for VS Code#

Microsoft AI Tour 2025/26. Prototype with open models in the Foundry Toolkit Playground, iterate on prompts in Agent Builder, evaluate against a test dataset, then take the same work from prototype to a deployed, monitored agent.

Foundry Toolkit and Hosted Agents Workshop#

Build, test, and deploy single-agent and multi-agent Hosted Agents to Microsoft Foundry from VS Code, using the Foundry Toolkit and Microsoft Agent Framework in Python.
