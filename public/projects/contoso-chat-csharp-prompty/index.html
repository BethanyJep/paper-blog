Contoso Chat - C# Prompty

November 15, 2024

This project showcases how to build a sophisticated retail copilot using C# and Prompty, implementing modern AI patterns like Retrieval-Augmented Generation (RAG).

Project Highlights#

  • Code-First Approach: Built entirely with C# and .NET
  • Prompty Integration: Uses Prompty for prompt management and orchestration
  • RAG Implementation: Combines retrieval with generation for accurate responses
  • Retail Domain: Specialized for e-commerce and customer service scenarios

Architecture#

The application follows a clean architecture pattern:

  • Presentation Layer: Web API for client interactions
  • Business Logic: Core copilot functionality
  • Data Layer: Vector database for product information
  • AI Services: Azure OpenAI for language processing

Key Features#

  • Product recommendations based on user queries
  • Natural language product search
  • Customer service automation
  • Multi-turn conversation support
  • Context-aware responses

Technologies Deep Dive#

Prompty#

  • Manages prompts as code
  • Version control for prompt engineering
  • Type-safe prompt execution

RAG Implementation#

  • Vector embeddings for product catalog
  • Semantic search capabilities
  • Context injection for accurate responses

Getting Started#

  1. Clone the repository
  2. Configure Azure OpenAI connection
  3. Set up the product database
  4. Run the application

Perfect for developers looking to build production-ready AI applications with .NET and modern AI patterns!
