Explore and Evaluate AI models for free with GitHub Models

🛠 I have the workshop; you just need to try it out and tell me what you think! I recently converted my workshop from Azure AI to GitHub Models, and it will be globally used as introductory content for the Global AI Bootcamps all over the world in ~125 locations. One of the biggest advantages of using GitHub Models is it provides every GitHub user access to some leading models from Azure AI Model Catalog, allowing you to experiment, test and compare models before you get them to production. Another plus of using GitHub Models is you only need to create your personal token to get started and going - no complicated setup, no friction.
